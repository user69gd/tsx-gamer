# Retro Space Shooter
A high-performance web game built with **TypeScript**, **React (TSX)**, and **CSS**.

## 🎮 Overview
Retro Space Shooter is an intense arcade-style game where players must navigate through asteroid fields and dodge enemy fire. The goal is to survive as long as possible while racking up the highest score to climb the leaderboard.

## 🚀 Features
* **Modern Stack**: Built using Vite, TypeScript, and React for a fast, component-driven architecture.
* **Responsive UI**: Custom CSS styling that adapts to your screen size.
* **Efficient Engine**: Optimized game loop using `requestAnimationFrame`.
* **Type-Safe Logic**: Leveraging TypeScript to ensure robust and maintainable game mechanics.

## 🛠️ Getting Stared

### Prerequisites
* [Node.js](https://nodejs.org/) (latest LTS recommended)
* npm or yarn

### Installation
1. Clone the repository:
```bash
git clone https://github.com/user69gd/retro-space-shooter.git
```
2. Navigate to the project directory:
```bash
cd retro-space-shooter
```
3. Install dependencies:
```bash
npm install
```

### Running the Project
To start the development server, run:
```bash
npm run dev
```
